# RadioCode — Demo-Terminal (statisch)

Demo eines Autoradio-Code-Service. Codes werden lokal im Browser berechnet,
die Zahlung ist **simuliert** (kein Geld, kein Zahlungsanbieter).

Nur Renault/Dacia (öffentlich dokumentierter Precode-Algorithmus).
Kein kommerzieller Dienst, keine echten Kundendaten.
